# Chào XO Kitchen demo

This is a static HTML/CSS/JavaScript website in `chao-xo-kitchen/`. There are no application dependencies or build steps.

Use the **Start application** workflow to run the site in Replit Preview. It serves the `chao-xo-kitchen/` directory on port 5000 with:

```sh
python3 -m http.server 5000 --bind 0.0.0.0 --directory chao-xo-kitchen
```

The page is a draft demo, not launch-ready. See `chao-xo-kitchen/client-spec.md` for unconfirmed details, placeholder contact information, and photo permissions that need resolving before publishing.
